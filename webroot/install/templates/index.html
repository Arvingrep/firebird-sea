安装提示：

1. 用户名/手机/邮箱和密码是您登录官方网站的帐号，如果您忘记密码请找回密码！

2. windows用户如果服务器开启了安全狗目录保护，请暂时关闭，否则会安装失败！

3. 如果启用了https，请暂时关闭强制跳转，使用http协议进行安装，否则会安装失败！

4. 请暂时关闭防跨站攻击，删除网站根目录的.user.ini文件，或者在宝塔面板中修改站点，网站目录中，不勾选 【防跨站攻击(open_basedir)】！

5. 环境要求：PHP7.4、MySQL5.5/5.6/5.7
