# 密钥存量欠债登记表
#
# 这个文件**不是豁免清单，是欠债清单**。用途只有两个：
#   1. 让门禁能区分「历史上已存在」与「本次新引入」——新引入一律 FAIL，不给商量；
#   2. 给每一笔历史欠债一个**硬到期日**，到期当天门禁自动转 FAIL，逼着处理。
#
# 格式（空格分隔，一行一笔）：
#   <仓库相对路径>  <到期日 YYYY-MM-DD>  <原因 / 跟踪项>
#
# 规则：
#   - 到期日解析失败 → 视为已过期 → FAIL（宁严勿松）
#   - 续期必须同时写明「为什么这轮没做完」，不接受无理由延期
#   - 轮换完成后，从本文件删除该行，并在 PR 描述里写明轮换动作与时间
#
# 扫描逻辑见 scripts/agent/gates.sh 第 6 项。
